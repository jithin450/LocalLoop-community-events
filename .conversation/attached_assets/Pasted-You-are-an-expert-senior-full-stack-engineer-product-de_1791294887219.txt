# 18. DATABASE SECURITY
--------------------------------------------------

This is extremely important.

Implement Supabase Row Level Security.

Enable RLS on every application table.

Users can:

Profiles:
- view public profiles
- update only their own profile

Events:
- everyone can view published events
- authenticated users can create events
- organizers can update only their own events
- organizers can delete/cancel only their own events
- admins can manage all events

Event attendees:
- authenticated users can RSVP themselves
- authenticated users can cancel their own RSVP
- organizers can view attendees of their own events
- admins can view all attendees

Saved events:
- users can create/delete/view only their own saved events

Reports:
- authenticated users can create reports
- users can view their own reports
- admins can manage reports

Notifications:
- users can view/update only their own notifications

Write all SQL policies.

Never disable RLS just to make the application work.
